## Project Description

This project demonstrates an end-to-end data analytics and visualisation workflow, transforming raw data into meaningful insights through data integration, cleaning, preprocessing, SQL analysis, Excel integration, and interactive Tableau dashboards.

The project began with **SQL Server Integration Services (SSIS)**, which was used for data extraction, cleaning, transformation, and preprocessing. The prepared data was then analysed using **SQL queries** to extract relevant information and generate analytical outputs.

The results were subsequently integrated with **Microsoft Excel** for further organisation and analysis. Finally, **Tableau** was used to develop interactive dashboards and visualisations, presenting key findings in a clear and business-focused format.

### Workflow

Raw Data → SSIS ETL → Data Cleaning & Transformation → SQL Analysis → Excel Integration → Tableau Dashboards
